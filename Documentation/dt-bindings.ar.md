# نموذج شجرة الأجهزة في lk2nd
[English](dt-bindings.md)

يستخدم lk2nd DT للتحكم (control DT) لتخزين التكوين الخاص بكل جهاز.
غالبًا لا يسمح محمّل الإقلاع الأولي على الجهاز باختيار DT فريد لكل جهاز،
لذا يعتمد lk2nd على نموذج DT خاص يتيح لمشاركة نفس ملف DT بين
عدة أجهزة.

> [!NOTE]
> صيغة DT في lk2nd مخصصة وغير متوافقة مع تعريفات DT القياسية في
> الصناعة المستخدمة في Linux. ومع ذلك، يحاول lk2nd إبقاء تعريفاته
> المخصصة مشابهة للمعايير الصناعية حيثما أمكن ذلك.

## تخطيط DT

بشكل عام يحتوي ملف lk2nd على جزأين:
 - العقدة الجذرية (root node). تحتوي هذه العقدة على المعلومات التي يحتاجها محمّل الإقلاع السابق.
 - عقدة lk2nd. تحتوي هذه العقدة على جميع المعلومات الخاصة بالجهاز المستخدمة من قبل lk2nd.

### العقدة الجذرية

يحتوي هذا القسم عادةً فقط على msm-id و board-id. بالنسبة لـ lk2nd يجب أن تحتوي
هذه العقدة فقط على الخصائص أو العقد التي يريد محمّل الإقلاع الأصلي رؤيتها
لإقلاع الصورة. لا يستخدم lk2nd هذه البيانات بشكل عام.

```
/ {
	qcom,msm-id = <QCOM_ID_MSM8916 0>;
	qcom,board-id = <0xCE08FF01 1>, <0xCE08FF01 3>, <0xCE08FF01 7>;
};
```

### عقدة lk2nd

يحتوي هذا القسم على معلومات جميع الأجهزة المدعومة من قبل هذا
الملف dt المحدد. يتم إدراج كل جهاز مدعوم في عقدة فرعية مخصصة.
إذا كان معروفًا أن ملف dt سيطابق جهازًا واحدًا فقط، فيمكن
وضع المعلومات الخاصة بالجهاز في عقدة lk2nd العلوية.

```
&lk2nd {
	a3lte {
		model = "Samsung Galaxy A3 (SM-A300F)";
		/* ... */
	};

	gt58lte { /* ... */ };
};
```

```
&lk2nd {
	model = "Huawei Y635-L01";
	/* ... */
};
```

## عقدة الجهاز

تحتوي عقدة الجهاز على جميع المعلومات التي يحتاجها lk2nd.

### Model و compatible

يجب أن يسرد كل جهاز قيمة `model` الخاصة به وقائمة قيم `compatible`.
لاحظ أن `model` يجب أن يحتوي على الاسم التسويقي للجهاز (ما
كُتب على العلبة) وليس أي شيء يمكن إيجاده في DT المعتمد
( downsteam DT).

بالإضافة إلى ذلك، يمكن أن تكون الخاصية `lk2nd,dtb-files` موجودة مع قائمة
بالأسماء المحتملة لشجرة الأجهزة لهذا الجهاز. لا تضف بادئة `qcom/` أو
`qcom-` ولا لاحقة `.dtb` إلى القيم لأن lk2nd سيضيفها حسب الحاجة.

```
	gt58lte {
		model = "Samsung Galaxy Tab A 8.0 (LTE, SM-T355)";
		compatible = "samsung,gt58lte", "samsung,gt58";
		lk2nd,dtb-files = "msm8916-samsung-gt58";
	};
```

### خاصية المطابقة (Match)

عندما يحتوي ملف DT على عدة أجهزة، يحتاج lk2nd إلى طريقة ليعرف
على أيّ منها أقلع. توجد عدة خصائص مطابقة للمساعدة في ذلك.

#### حسب محمّل الإقلاع

يمكن لـ lk2nd فحص سطر أوامر محمّل الإقلاع السابق ومطابقة
المعامل `android.bootloader=` مع تعبير (expression):

```
	lk2nd,match-bootloader = "A300F*";
```

#### حسب سطر الأوامر

مثل match-bootloader، لكن يفحص سطر الأوامر بأكمله بحثًا عن تطابق:

```
	lk2nd,match-cmdline = "*lenok*";
```

#### حسب الجهاز

يمكن لـ lk2nd فحص سطر أوامر محمّل الإقلاع السابق ومطابقة
المعامل `android.device=` مع تعبير:

```
	lk2nd,match-device = "victara";
```

#### حسب لوحة العرض

في بعض الحالات لا يوجد معامل سطر أوامر مفيد للمطابقة عليه، لذا
من الممكن استخدام قائمة بلوحات العرض المحتملة والمطابقة إذا
كانت واحدة منها موجودة. راجع [اختيار اللوحة](#اختيار-اللوحة).

```
	lk2nd,match-panel;
	panel { /* ... */ };
```

### اختيار اللوحة

تشحن العديد من الأجهزة مع إحدى عدة وحدات عرض محتملة.
يمكن لـ lk2nd تصحيح شجرة أجهزة نظام التشغيل لإدراج قيمة
متوافقة للعرض المكتشف. يرجى سرد جميع اللوحات المحتملة
عند إضافة جهاز جديد، إذا كنت تخطط للاستفادة من هذا.

```
	panel {
		compatible = "wingtech,wt88047-panel", "lk2nd,panel";

		qcom,mdss_dsi_r69431_720p_video {
			compatible = "wingtech,sharp-r69431";
		};
		qcom,mdss_dsi_nt35521_720p_video {
			compatible = "wingtech,auo-nt35521";
		};
		/* ... */
	};
```

#### Sony lcdid_adc

بعض أجهزة Sony تمرر فقط معامل `lcdid_adc` لاختيار
اللوحات. يتم تحديد اللوحة بمجموعة من القيم.

```
	panel {
		compatible = "sony,aries-panel", "lk2nd,panel";

		novatek_jdi_720p_cmd {
			compatible = "sony,novatek-jdi-720p-cmd";
			sony,lcd-id-adc = <0x109618 0x12c898>;
		};

		novatek_sharp_720p_cmd {
			compatible = "sony,novatek-sharp-720p-cmd";
			sony,lcd-id-adc = <0x562e8 0x65130>;
		};
	};
```

### تجاوز msm-id

لبعض الأجهزة، قد يكون من الضروري إعلام lk2nd بمعرّفات msm و
board التي يجب استخدامها عند إقلاع النواة المعتمدة.
يمكنك تحديدها في عقدة الجهاز وسيستخدمها lk2nd بدلًا من
الكشف التلقائي.

```
	qcom,msm-id = <QCOM_ID_MSM8916 0>;
	qcom,board-id = <0xCE08FF01 1>;
```

### التنقل بمفتاح واحد

على بعض الأجهزة، مثل الساعات الذكية، لا يوجد سوى مفتاح واحد متاح
للتنقل. في هذه الحالة يمكن استخدام الخاصية `lk2nd,single-key-navigation`
لتبديل نظام التنقل إلى ضغط قصير/طويل على مفتاح واحد.

```
	lk2nd,single-key-navigation;
```

### تلميح مفاتيح التنقل المخصص في القائمة

إذا كان جهازك يستخدم مفاتيح مُعاد تعيينها، يمكنك تخصيص التلميح
الذي يظهر في قائمة إقلاع lk2nd.

على سبيل المثال، إذا كان جهازك يحتوي فقط على مفتاحي `Volume Up` و
`Volume Down` ولا يحتوي على مفتاح `Power`، يمكنك إضافة
الخاصية الاختيارية التالية:

```
	lk2nd,menu-key-strings = "Volume Down", "Volume Up";
```

تصف السلسلة الأولى المفتاح (المفاتيح) المستخدمة للتنقل في القائمة،
وتصف السلسلة الثانية المفتاح المستخدم لتحديد عنصر القائمة.

مع إعداد المثال المعروض أعلاه، ستقرأ قائمة الإقلاع:

  Volume Down to navigate.
  Volume Up to select.

إذا لم يتم تعيين الخاصية، سيظهر التلميح الافتراضي:

  Volume keys to navigate.
  Power key to select.

### فتحة بطاقة SD MMC

إذا كان جهازك يحتوي على بطاقة SD خارجية معيّنة لرقم فتحة مختلف عن
العادة، يمكنك تحديد الفتحة التي سيفحصها lk2nd بحثًا عن بطاقة SD.

على سبيل المثال، إذا كان جهازك يعيّن البطاقة الخارجية للفتحة 3، يمكنك
إضافة الخاصية التالية:

```
	lk2nd,sd-mmc = <&sdhc3>;
```

القيم المتاحة هي `<&sdhc2>` و `<&sdhc3>`.

هذا الإعداد ينطبق فقط على المنصات التالية:
- msm8974

ملاحظة: للمنصات التي ينطبق عليها هذا، **يجب** تعيين
هذه الخاصية في dts الخاص بالجهاز في lk2nd حتى يعمل الإقلاع من بطاقة SD.

## تعريفات (Drivers) إضافية

يوفّر lk2nd مجموعة من العقد الاختيارية، وفقًا لنموذج تعريفات
بسيط.

### مفاتيح GPIO

إذا كان لدى جهاز خريطة مفاتيح غير افتراضية لمفاتيح الصوت والكهرباء،
يمكن تجاوزها بعقدة `gpio-keys`. تتبع هذه العقدة التعريف
القياسي مع استثناء الخاصية الجديدة `lk2nd,code`.

```
	gpio-keys {
		compatible = "gpio-keys";

		volume-down {
			lk2nd,code = <KEY_VOLUMEDOWN>;
			gpios = <&tlmm 81 (GPIO_ACTIVE_LOW | GPIO_PULL_UP)>;
		};
		home {
			lk2nd,code = <KEY_HOME>;
			gpios = <&pmic 3 (GPIO_ACTIVE_LOW | GPIO_PULL_UP)>;
		};
	};
```

يمكنك أيضًا استخدام هذا لإعادة تعيين المفاتيح للسماح بالتنقل في القائمة
إذا لم تكن المفاتيح الافتراضية متوفرة على الجهاز.

المثال التالي لجهاز يحتوي فقط على مفتاحي Volume Up و Down، لكن
لا يحتوي على مفتاح Power. يعيد تعيين مفتاح Volume Up إلى مفتاح
Power للسماح بتحديد العناصر في القائمة.

لاحظ أنه قد تحتاج إلى إلغاء تعيين مفتاح معين عن وظيفته الأصلية
بإسناد GPIO غير مستخدم مكانه. في هذه الحالة يهم ترتيب العقد في
شجرة أجهزتك، لذا تأكد من إلغاء تعيين المفتاح أولًا قبل إسناد
رمز مفتاح جديد للمفتاح الفعلي.

```
	gpio-keys {
		compatible = "gpio-keys";

		/* HACK: map KEY_VOLUMEUP to non-existent button so the actual
		 * Volume Up button will successfully re-map to KEY_POWER below.
		 */
		volume-up-unmap {
			lk2nd,code = <KEY_VOLUMEUP>;
			gpios = <&pmic_pon 0 0>;
		};

		/*
		 * Remap Volume Up to KEY_POWER to allow selecting menu items as
		 * there is no power button present on the device.
		 * Use Volume Down to navigate the menu and Volume Up to select.
		 */
		volume-up {
			lk2nd,code = <KEY_POWER>;
			gpios = <&tlmm 85 (GPIO_ACTIVE_LOW | GPIO_PULL_UP)>;
		};
	};
```

### مصابيح GPIO

يدعم lk2nd عقدة `gpio-leds`. تتبع هذه العقدة التعريف القياسي باستثناء
أن معظم الخصائص غير مدعومة. حاليًا فقط `gpios` و
`default-state` مدعومتان في lk2nd.

```
gpio-leds {
    compatible = "gpio-leds";

    red {
        gpios = <&tlmm 3 GPIO_ACTIVE_HIGH>;
        default-state = "on";
    };

    green {
        gpios = <&tlmm 4 GPIO_ACTIVE_HIGH>;
        default-state = "off";
    };
};
```

هذا التعريف مخصص أساسًا لـ lk1st لأنه لا يوجد محمّل إقلاع سابق قادر
على إضاءة LED في هذه الحالة. هذا يجعل حالة الجهاز الحالية غير واضحة.
إذا أردت التأكد من تفعيل أو إلغاء تفعيل بعض المصابيح عند
الإقلاع بواسطة lk1st، يمكنك استخدام هذا التعريف.

لا ينفّذ lk2nd نظام LED متكاملًا. الغرض الوحيد من
هذا التعريف هو التصحيح واتساق سلوك LED بين lk1st
و lk2nd.

### منظّم ثابت (Fixed Regulator)

يدعم lk2nd عقدة `regulator-fixed`. تتبع هذه العقدة التعريف القياسي باستثناء
أن معظم الخصائص غير مدعومة. حاليًا فقط `gpios` مدعومة في lk2nd.

```
regulator-backlight {
    compatible = "regulator-fixed";
    gpios = <&tlmm 9 GPIO_ACTIVE_HIGH>;
};
```

هذا التعريف مخصص أساسًا لـ lk1st لأنه لا يوجد محمّل إقلاع سابق قادر
على تشغيل تلك المنظّمات المطلوبة من قبل اللوحة والإضاءة الخلفية.
إذا كانت لوحة جهازك والإضاءة الخلفية تتطلبان تشغيل منظّم معين،
يمكنك استخدام هذا التعريف.

لا ينفّذ lk2nd نظام منظّمات متكاملًا. الغرض الوحيد من
هذا التعريف هو تشغيل تلك المنظّمات المطلوبة من قبل اللوحة والإضاءة الخلفية
واتساق سلوك المنظّم بين lk1st و lk2nd.

### منظّم LDO

يدعم lk2nd عقدة `regulator-ldo`. هذه العقدة لها تعريفات محددة
في `dt-bindings/lk2nd/regulator.h`.
هذا التعريف بسيط جدًا، وقادر فقط على تفعيل المنظّم المحدد.

```
#include <dt-bindings/lk2nd/regulator.h>

regulator-l11 {
    compatible ="regulator-ldo";
    id = <REG_LDO11>;
};
```
